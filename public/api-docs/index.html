勤務表の公開API

外部サービスから勤務状態、勤務表、日本の祝日を取得できる 読み取り専用のJSON APIです。日付と時刻は日本時間を基準にしています。

エンドポイント

  • API一覧
  • 今日・次の仕事・次の休み
  • 今日の勤務状態
  • 次の休み
  • 指定日から14日分の勤務表（例）
  • 指定月の勤務表（例）
  • 指定年の日本の祝日（例）

利用方法

すべてのエンドポイントは認証不要で、GET と HEAD に対応しています。ブラウザなどの外部サービスから 利用できるよう、Access-Control-Allow-Origin: * を返します。
